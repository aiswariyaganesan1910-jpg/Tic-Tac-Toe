# Tic Tac Toe Game in C++

## Project Overview
This project is a console-based Tic Tac Toe game developed using C++. The application allows two players to play the game interactively through the terminal. The project demonstrates the implementation of core programming concepts such as arrays, loops, functions, and conditional statements.

The game dynamically updates the board after every move, checks for winning conditions, detects draw situations, and provides an option to replay the game.

---

# Objective
To develop an interactive Tic Tac Toe game using C++ that demonstrates game logic implementation and problem-solving skills using structured programming concepts.

---

# Features
- Two-player gameplay
- Dynamic game board display
- Win condition detection
- Draw condition detection
- Input validation
- Replay option after game completion
- Simple and user-friendly console interface

# How to Run the Project

## Step 1: Save the File
Save the source code as:

```bash
tictactoe.cpp
```

---

## Step 2: Open Terminal
Open:
- Command Prompt
- VS Code Terminal
- Any C++ supported terminal

---

## Step 3: Navigate to File Location

Example:

```bash
cd Desktop
```

---

## Step 4: Compile the Program

```bash
g++ tictactoe.cpp -o game
```

---

## Step 5: Run the Program

### Windows

```bash
game.exe
```

### Linux / Mac

```bash
./game
```
